# Резервные копии сайта

В этой папке хранятся точечные резервные копии файлов `Solargy.kz`, сделанные перед изменениями через административную часть Bitrix.

Каждая операция размещается в отдельной папке с датой и кратким назначением. Внутри должен находиться исходный файл до правки и инструкция по восстановлению.

Резервные копии не содержат паролей, ключей доступа, баз данных или пользовательских заявок.
