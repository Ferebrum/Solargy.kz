| Поле | Шаблон |
| --- | --- |
| `title` элемента | `{=this.Name} — SOLARGY Казахстан` |
| `description` элемента | `{=this.Name} — новости о световодах и системах естественного освещения SOLARGY в Казахстане.` |

Это правильная базовая модель для новых новостей: заголовок новости подставляется автоматически, а автору не нужно вручную собирать базовую SEO-формулировку.

## Что делать сейчас

1. Не менять массово текущие `title` и `description`.
2. Подготовить небольшой список проверочных URL по каждому типу контента и отправить их на переобход в Яндекс Вебмастере.
3. После нового обхода повторно проверить список дублей.
4. Если дубли останутся, выгрузить точный список URL и разбирать только реальные исключения.
5. Для авторов новых новостей сохранить правило: название новости должно быть содержательным; SEO-шаблон подставит основу автоматически, а ручные SEO-поля нужны только для осознанных исключений.

## Следующее согласование

Следующее внешнее действие — отправить на переобход 5–10 репрезентативных URL. Это не меняет сайт, но просит Яндекс обновить данные о страницах.
