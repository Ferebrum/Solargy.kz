# Актуальная проверка новостей Solargy.kz

Дата: 21 августа 2026
Статус: исправления выполнены и публично проверены

## Источники

- актуальные таблицы CSV из Яндекс Вебмастера по повторяющимся `title` и `description`;
- 50 публичных URL раздела `/news/`;
- инфоблок Bitrix «Новости», ID `7`;
- карточки элементов Bitrix;
- Solargy.ru как исходный сайт для проверки двух недоступных материалов.

## Состояние отчёта Вебмастера

Вебмастер продолжает показывать:

- 44 URL новостей с заголовком `Новости | SOLARGY`;
- 46 URL с описанием `Свежие новости про компанию и продукцию SOLARGY`;
- две дополнительные пары новостей с одинаковыми описаниями.

Даты обхода основной массы URL — 12–14 августа 2026. Эти данные частично устарели относительно текущих настроек Bitrix.

## Результат проверки 50 публичных URL

- все 50 URL отвечают HTTP 200;
- 45 уникальных `title`;
- 43 уникальных `description`;
- у всех есть canonical;
- массовый дубль 44 заголовков карточек уже устранён: все 44 карточки имеют уникальный `title`;
- массовый дубль описаний карточек также устранён текущим шаблоном, кроме двух реальных пар ручных значений;
- шесть страниц списков используют общий `title` и `description`;
- две выключенные карточки являются мягкими ошибками 404 при ответе HTTP 200.

## Причина дублей страниц рубрик

В настройках инфоблока пусты шаблоны:

- `SECTION_META_TITLE`;
- `SECTION_META_DESCRIPTION`;
- `SECTION_PAGE_TITLE`.

Поэтому `/news/` и часть рубрик используют общий запасной заголовок `Новости SOLARGY в Казахстане` и общее описание. Безопасное исправление на уровне инфоблока:

```text
SECTION_META_TITLE: {=this.Name} — новости SOLARGY Казахстан
SECTION_META_DESCRIPTION: {=this.Name} — новости и материалы о световодах, системах естественного освещения и расчёте КЕО SOLARGY в Казахстане.
SECTION_PAGE_TITLE: {=this.Name}
```

Шаблоны применяются к рубрикам; явно заданные индивидуальные значения Bitrix должны сохранять приоритет.

## Реальные пары дублей карточек

### ID 28 и ID 107

- ID `28`: `10 ЛЕТ «СОЛАРЖИ»`;
- ID `107`: `Поможем врачам: медицина и естественный свет SOLARGY`.

У ID `107` ошибочно скопирован анонс и SEO-description из статьи об истории компании. Предлагаемое описание:

> Естественный свет в медицинских учреждениях: как световоды SOLARGY помогают улучшить условия для пациентов и медицинского персонала.

Это же содержание нужно использовать как исправленный анонс ID `107`.

### ID 160 и ID 170

- ID `160`: `Производство Световодов Solargy`;
- ID `170`: `Телеканал Россия снял видеосюжет о световодах`.

У ID `170` SEO-description ошибочно скопирован из ID `160`, хотя анонс уже уникален. Предлагаемое описание:

> Сюжет телеканала «Россия» о световодах SOLARGY: журналисты показали производство и технологию естественного освещения.

Для единообразия предлагается также уточнить ручные `title` и descriptions ID `28` и ID `160`, не меняя основной текст материалов.

## Выполненный пакет исправлений

1. Заполнить три SEO-шаблона разделов инфоблока `7`.
2. Исправить анонс и SEO-метаданные ID `107`.
3. Исправить SEO-метаданные ID `170`.
4. Привести ручные SEO-title ID `28` и ID `160` к формату с брендом и сделать descriptions более содержательными.
5. Включить ID `392` и ID `393`, затем проверить обе публичные страницы.
6. Повторно проверить все 50 URL на уникальность метаданных, HTTP-статус, H1 и canonical.
7. Отправить ключевые URL на переобход после завершения общего пакета работ.

Дополнительно установлено, что ID `392` и `393` выводились через отдельный устаревший `/include/news_custom.php`, который игнорировал текст карточки Bitrix. Исключение в шаблоне отключено, оба материала переписаны для Казахстана и переведены на стандартный управляемый вывод.

Контрольный обход после исправлений: 50 из 50 URL имеют H1, `title`, `description` и canonical; дублей заголовков и описаний в выборке нет, пустые страницы не обнаружены. Подробная запись: `changes/2026-08-21-news-seo-and-content.md`.
