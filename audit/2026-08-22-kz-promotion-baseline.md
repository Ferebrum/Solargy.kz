# Solargy.kz: исходная точка продвижения

Дата проверки: 22 августа 2026 года.

## Подтверждено

- Проверяется самостоятельный казахстанский сайт `https://solargy.kz/`, а не зеркало российского сайта.
- `robots.txt` доступен с HTTP 200, содержит `Host: solargy.kz` и ссылку на `https://solargy.kz/sitemap.xml`.
- `sitemap.xml` доступен с HTTP 200 и включает 8 дочерних карт, всего 194 URL.
- Главная страница содержит `robots: index, follow`, canonical, `ru-KZ`, `kk-KZ` и разметку `Organization`.
- Казахстанская версия `/kk/` доступна с HTTP 200.
- В Яндекс Вебмастере для сайта вручную указан регион `Астана`.
- Вебмастер не показывает критических ошибок, но показывает две рекомендации:
  1. одинаковые заголовки и описания;
  2. организация не добавлена в Яндекс Бизнес.
- Сводка Вебмастера на момент проверки показывает 93 дублирующихся title и 99 дублирующихся description. Эти данные могут включать старый индекс и должны быть перепроверены после переобхода.
- В карте сайта обнаружены 14 устаревших URL с HTTP 404. Все они создаются инфоблоками 11 `Контактные лица` и 12 `Награды`:
  - 7 URL в `sitemap-iblock-11.xml`;
  - 7 URL в `sitemap-iblock-12.xml`.
- Публичный аудит 194 адресов дал 179 ответов HTTP 200 и 14 подтвержденных HTTP 404; `/builder/` отдельно отвечает HTTP 200.
- На живых страницах найдены небольшие группы дублей разделов: каталог, новости, проекты, документы и FAQ. Нужно определить альтернативные URL и оставить один индексируемый адрес для каждого раздела.
- Яндекс Метрика `Solargy.kz`, счетчик `111696868`, работает. За квартал распознана одна поисковая фраза: `соларжи кз`.
