## Приоритетные новые посадочные кластеры

1. `световоды для склада / естественное освещение склада Казахстан` — B2B-страница с расчётом КЕО, высотой помещения, схемой размещения и кейсами.
2. `световоды для производственного цеха Казахстан` — требования к промышленным помещениям, запылённость, обслуживание, узлы кровли.
3. `световоды для школы / детского сада Казахстан` — нормы естественного освещения, безопасность и расчёт для экспертизы.
4. `световой туннель для дома Казахстан / Астана / Алматы` — отдельная коммерческая страница без дублирования `/private/`, с подбором Crystal и компактным квизом.
5. `расчёт КЕО в Казахстане / расчёт естественного освещения` — услуга с перечнем исходных данных, составом результата и нормами РК; не смешивать с описанием программного комплекса RusKEO.
6. `зенитные фонари для склада и цеха` — коммерческий кластер на базе существующего `/zenitnye-fonari/`, предпочтительно расширить текущую страницу, а не создавать дубль.
7. `световоды для подвала / цокольного этажа` — связать со СветоСкопом, SWF и световыми колодцами.
8. `естественное освещение без окон` — информационно-коммерческая страница с развилкой по типу объекта.

## Правила публикации

- Одна основная страница на один поисковый замысел.
- Не создавать новые страницы под синонимы, если запрос закрывается существующим URL.
- В каждой посадочной странице использовать казахстанские контакты, тенге, местные кейсы и применимые нормы РК.
- Российский сайт использовать как источник технических фактов и структуры, но не копировать его текст.
- Перед публикацией собрать частотность и региональную выдачу отдельно для Казахстана, Астаны и Алматы.
- Связать посадочные страницы с каталогом, проектами, FAQ, расчётом КЕО и формой заявки.
