# Solargy.kz — журнал работ

Этот репозиторий хранит журнал анализа и согласованных работ по сайту [solargy.kz](https://solargy.kz/).

Исходники работающего сайта, ядро 1С-Битрикс, дампы, резервные копии и конфигурации с секретами сюда не выгружаются. Все изменения сайта выполняются в его рабочем окружении только после согласования.

## Структура

- `audit/` — снимки аудитов и результаты проверок;
- `changes/` — журнал выполненных и подтверждённых исправлений;
- `assets/` — только новые согласованные материалы, если они нужны для работы.

## Правила работы

1. Сначала фиксируем наблюдение и проверяем его влияние.
2. Затем согласовываем способ исправления.
3. После изменения в Битрикс или на хостинге фиксируем дату, затронутые страницы и результат проверки.
4. Секреты, персональные данные, выгрузки БД и копии сайта в репозиторий не добавляем.
