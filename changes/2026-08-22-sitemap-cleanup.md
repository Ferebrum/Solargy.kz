# Очистка sitemap Solargy.kz

Дата: 22 августа 2026 года.

## Что изменено в Bitrix

- В штатной настройке генерации sitemap отключены служебные инфоблоки:
  - №11 `Контактные лица`;
  - №12 `Награды`.
- Для инфоблоков проектов, новостей, документов, FAQ и каталога отключено повторное добавление страницы списка. Сами разделы уже входят в файловую карту сайта.
- Из файловой структуры sitemap исключён `/builder/`, который не является самостоятельной страницей и перенаправляет на `/ruskeo/`.
- Sitemap трижды перегенерирована штатным инструментом Bitrix после каждого этапа настройки.
- Обновлённая `https://solargy.kz/sitemap.xml` отправлена на переобход в Яндекс Вебмастере 22 августа 2026 года в 01:33.

## Проверка результата

- До исправления: 194 записи, из них 14 URL с HTTP 404 и пять повторяющихся адресов главных разделов.
- После исправления: 186 URL.
- Все 186 URL уникальны.
- Карты `sitemap-iblock-11.xml` и `sitemap-iblock-12.xml` исключены из индексной карты.
- `/builder/` исключён из sitemap.
- Контроль HTTP-кодов: 186 оставшихся URL отвечают HTTP 200.

## Дополнительное наблюдение

Редирект `/builder/` настроен в два этапа: сначала HTTP 301 на `http://solargy.kz/ruskeo/`, затем переход на HTTPS. В sitemap он больше не публикуется. Позже следует упростить правило сервера до одного перенаправления непосредственно на `https://solargy.kz/ruskeo/`.

## Следующий SEO-дефект

После очистки выявлен один фактический дубль метатегов:

- `https://solargy.kz/faq/`;
- `https://solargy.kz/faq/index/`.

Обе страницы сейчас получают title `Что такое световод — принцип работы SOLARGY` и одинаковое description. В исходнике `/faq/index.php` уже заданы правильные общие метатеги главной FAQ, но компонент `news.detail` перезаписывает их данными элемента с кодом `index`. Требуется отключить такое перезаписывание только для точного адреса `/faq/`, сохранив метаданные элемента для `/faq/index/`.
