# Журнал исправлений

В эту папку добавляется отдельный файл для каждой завершённой и проверенной группы изменений.

Шаблон записи:

```md
# YYYY-MM-DD — краткое название

- Статус: запланировано | выполнено | проверено | отменено
- Где изменено: Битрикс / хостинг / внешний сервис
- Затронутые URL или сущности:
- Причина:
- Что изменено:
- Как проверено:
- Что проверить после обхода роботом:
```

Не добавлять в журнал пароли, ключи, персональные данные или полные резервные копии.
