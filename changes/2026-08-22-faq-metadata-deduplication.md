# Устранение дубля метаданных FAQ

Дата: 22 августа 2026 года.

## Причина

Адреса `/faq/` и `/faq/index/` получали метаданные одного элемента инфоблока с кодом `index`. Компонент `bitrix:news.detail` перезаписывал общие title, description и H1 главной страницы FAQ.

## Что изменено

- В `/faq/index.php` добавлено определение точного адреса главной страницы `/faq/`.
- Только для главной `/faq/` отключена перезапись browser title, meta description и заголовка страницы компонентом `news.detail`.
- Для `/faq/index/` и остальных ответов FAQ прежняя настройка сохранена: каждый ответ продолжает использовать собственные метаданные элемента.
- Изменение выполнено через штатный редактор файлов Bitrix.

## Публичная проверка

### `/faq/`

- title: `Часто задаваемые вопросы о световодах, зенитных фонарях - SOLARGY`;
- description: `Что такое световод или зенитный фонарь. Как подобрать световод. Почему нужно оценивать освещение комплексно. Где применить световоды. Освещение помещений.`;
- H1: `Часто задаваемые вопросы`;
- canonical: `https://solargy.kz/faq/`.

### `/faq/index/`

- title: `Что такое световод — принцип работы SOLARGY`;
- description: `Что такое световод SOLARGY, из каких частей он состоит и как передаёт естественный свет в помещения без окон.`;
- canonical: `https://solargy.kz/faq/index/`.
