# Восстановление высоты главного баннера

Дата: 21 августа 2026 года.

## Проблема

Главный слайдер на `https://solargy.kz/` занимал всю ширину страницы, но его высота уменьшилась примерно до 108 пикселей, поэтому баннер выглядел очень узким.

## Причина

В `/local/templates/solargy/assets/css/custom.css` находилось переопределение:

```css
.main-section .owl-main .item {
    height: 15vh;
    min-height: 80%;
}
```

Правило перекрывало штатную высоту слайдера из основного файла стилей.

## Изменение

- Через редактор файлов Bitrix удалено ошибочное активное правило и его закомментированная копия.
- После дополнительной проверки фиксированная штатная высота 500 пикселей заменена в `custom.css` на адаптивную высоту окна браузера:

```css
.main-section.index-slider .owl-main .item {
    height: 100vh;
    height: 100svh;
    min-height: 500px;
}
```

- `100vh` служит совместимым базовым вариантом, а `100svh` корректно учитывает видимую высоту экрана на современных мобильных браузерах.
- Исходники сайта в репозиторий не копировались.

## Проверка

- Главная страница повторно загружена после сохранения с обходом кеша URL-параметром.
- При окне 1280 × 720 пикселей изображение занимает всю доступную ширину страницы 1264,8 пикселя.
- Высота активного слайда и изображения равна высоте окна — 720 пикселей; проверка `heightMatchesViewport` пройдена.
- Для изображения сохранён режим `object-fit: cover`.

## Откат

Для отката удалить блок «SOLARGY: адаптивный главный баннер по высоте экрана» из начала `custom.css`. После этого шаблон вернётся к фиксированной высоте 500/600 пикселей. Правило `height: 15vh` возвращать нельзя: оно снова уменьшит баннер примерно до 108 пикселей.
