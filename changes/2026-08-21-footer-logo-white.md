# Белый логотип в подвале Solargy.kz

Дата: 21 августа 2026
Статус: выполнено и проверено

## Задача

Сделать логотип в нижней части сайта белым на бирюзовом фоне, сохранив цветной вариант в шапке.

## Исходное состояние

- Шапка и подвал использовали один SVG-файл: `/local/templates/solargy/assets/img/solargy-logo.svg?v=20260820`.
- В подвале цветной оранжевый логотип имел недостаточно подходящее оформление для бирюзового фона.
- Подвал уже имел отдельный селектор `.logo-f`, поэтому менять сам SVG или создавать его копию не требовалось.

## Изменение

Через редактор файлов административной части Битрикс в файл
`/local/templates/solargy/assets/css/custom.css` добавлено правило:

```css
/* Белый логотип в подвале на бирюзовом фоне */
footer .logo-f img {
  filter: brightness(0) invert(1);
}
```

Правило действует только внутри блока логотипа подвала.

## Проверка результата

После сохранения публичная главная страница была перезагружена:

- нижний логотип использует `filter: brightness(0) invert(1)`;
- размер нижнего логотипа остался 185×45,4 px;
- верхний логотип по-прежнему использует `filter: none`;
- оба места продолжают загружать один серверный SVG-файл.

## Откат

Для отмены изменения достаточно удалить из `custom.css` приведённый выше CSS-блок. Другие настройки и файлы менять не требуется.
